HOW TO USE THIS STRUCTURE
================================================================================

1. DEVELOPMENT
   - Work in src/ for source files
   - Work in include/ for headers
   - Keep namespace prod {} for all new code
   - Follow the file organization pattern

2. BUILDING
   platformio run                    Production build
   platformio run -e charger_esp32_debug     Debug build
   platformio run --target clean     Clean build
   platformio run --target upload    Upload to device

3. DEBUGGING
   platformio debug                  Start debugger
   platformio device monitor         Monitor serial output
   platformio device list            List connected devices

4. TESTING
   cd test/unit/                     Run unit tests
   cd test/integration/              Run integration tests
   platformio ci                     Continuous integration

5. DEPLOYMENT
   buildd/build.bat                  Build script
   tools/scripts/serve_firmware.py   Start OTA server
   deployment/firmware/              Store releases
   deployment/certificates/          Manage certificates

6. DOCUMENTATION
   docs/                             Read all documentation
   FOLDER_STRUCTURE.txt             Understanding structure
   QUICK_REFERENCE.md               Quick commands

================================================================================
FILE ORGANIZATION PRINCIPLES
================================================================================

1. Separation of Concerns
   - drivers/    : Hardware abstraction
   - modules/    : Feature modules
   - config/     : Configuration & constants
   - utils/      : Shared utilities

2. Include File Pairing
   - Every .cpp has a corresponding .h
   - include/ mirrors src/ structure
   - Keep same filenames for clarity

3. Namespace Isolation
   - Production: namespace prod {}
   - External libs: keep original namespaces
   - Tests: namespace test {}

4. Consistent Naming
   - Files: snake_case (e.g., ocpp_manager.cpp)
   - Classes: PascalCase (e.g., OCPPManager)
   - Variables: camelCase (e.g., ocppTaskHandle)
   - Constants: UPPER_CASE (e.g., PLUG_DEBOUNCE_MS)
