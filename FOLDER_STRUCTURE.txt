================================================================================
DIRECTORY ORGANIZATION PRINCIPLES
================================================================================

1. SEPARATION OF CONCERNS
   - Drivers: Hardware abstraction
   - Modules: Feature implementations
   - Config: Settings & constants
   - Utils: Shared utilities

2. NAMESPACE ORGANIZATION
   - All production code: namespace prod {}
   - External libraries: Original namespaces
   - Tests: namespace test {}

3. HEADER/SOURCE PAIRING
   - include/ mirrors src/ structure
   - Every .cpp has corresponding .h
   - Headers in include/XXX/ vs src/XXX/

4. THIRD-PARTY LIBRARIES
   - lib/ contains all external libraries
   - lib/MicroOcpp : Main OCPP implementation
   - lib/mcp2515 : CAN driver library

5. CONFIGURATION HIERARCHY
   - platformio.ini : Build configuration
   - include/config/hardware.h : Hardware pins
   - include/config/timing.h : Timing values
   - include/secrets.h : Credentials (git ignored)

TYPICAL WORKFLOW
================================================================================

1. BUILDING
   └─> platformio run
   └─> Output: .pio/build/charger_esp32_production/firmware.bin

2. DEBUGGING
   └─> PlatformIO: Debug (via VS Code)
   └─> Or: platformio debug

3. MONITORING
   └─> platformio device monitor
   └─> Monitor serial output at 115200 baud

4. DEPLOYING
   └─> tools/scripts/serve_firmware.py (start OTA server)
   └─> Charger pulls firmware & updates automatically

5. TESTING
   └─> test/unit/ : Unit tests
   └─> test/integration/ : Full system tests

================================================================================
FUTURE EXPANSION
================================================================================

Adding New Feature:
  1. Create src/modules/my_feature.cpp
  2. Create include/my_feature.h
  3. Add to namespace prod {}
  4. Include in src/main.cpp
  5. Add tests in test/unit/test_my_feature.cpp

Adding New Driver:
  1. Create src/drivers/my_driver.cpp
  2. Create include/drivers/my_driver.h
  3. Add abstraction in can_driver.h (if CAN-related)
  4. Implement in namespace prod {}

Adding New Config:
  1. Create include/config/my_config.h
  2. Add constants/macros
  3. Reference in src/config/config.cpp
