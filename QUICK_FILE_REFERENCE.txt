IF YOU NEED TO...
================================================================================

Modify hardware pins
  ├─ Edit: include/config/hardware.h
  └─ Also check: src/drivers/can_mcp2515_driver.cpp (if CAN pins)

Change timing intervals
  ├─ Edit: include/config/timing.h
  └─ Use: Connect the values in your code

Update OCPP protocol
  ├─ Edit: src/modules/ocpp_manager.cpp
  ├─ Edit: src/modules/ocpp_state_machine.cpp
  └─ Reference: lib/MicroOcpp/ (OCPP library)

Add CAN communication
  ├─ Edit: src/drivers/can_driver.cpp (abstraction)
  ├─ Or: src/drivers/can_mcp2515_driver.cpp (MCP2515)
  ├─ Or: src/drivers/can_twai_driver.cpp (ESP32 TWAI)
  └─ Header: include/drivers/can_driver.h

Configure charger
  ├─ Edit: src/drivers/charger_interface.cpp
  ├─ Check: include/config/hardware.h (pins)
  └─ Header: include/drivers/charger_interface.h

Setup WiFi
  ├─ Edit: src/modules/wifi_manager.cpp
  ├─ Check: include/secrets.h (credentials)
  └─ Template: include/secrets.h.example

Debug an issue
  ├─ Check: src/modules/debug_console.cpp
  ├─ Read: docs/DEBUG_MENU.md
  ├─ Use: platformio device monitor
  └─ Set breakpoints in: .vscode/launch.json

Build the project
  ├─ Run: platformio run
  ├─ Or: tools/build/build.bat (Windows)
  ├─ Output: .pio/build/charger_esp32_production/
  └─ Binary: firmware.bin

Deploy to charger
  ├─ Build: platformio run
  ├─ Run OTA server: python tools/scripts/serve_firmware.py
  ├─ Charger: connects and updates automatically
  └─ Check: deployment/firmware/ for releases

Run tests
  ├─ Unit tests: test/unit/
  ├─ Integration: test/integration/
  └─ Use: platformio run --target test

Add a new module
  1. Create: src/modules/my_feature.cpp
  2. Create: include/my_feature.h
  3. Include in: src/main.cpp
  4. Use namespace: prod {}
  5. Add tests: test/unit/test_my_feature.cpp

View documentation
  ├─ Overview: README.md
  ├─ Structure: FOLDER_STRUCTURE.txt
  ├─ Guides: docs/ (20+ files)
  └─ Quick help: QUICK_REFERENCE.md

================================================================================
NAMESPACE ORGANIZATION
================================================================================

All production code goes in: namespace prod {}

Key classes:
  prod::OCPPManager              OCPP protocol
  prod::OCPPStateMachine         State machine
  prod::HealthMonitor            Health & watchdog
  prod::PersistenceManager       NVS storage
  prod::CANDriver                CAN abstraction
  prod::ChargerInterface         Charger control
  prod::SecurityManager          SSL/TLS
  prod::WiFiManager              Network

External libraries use their own namespaces (MicroOcpp, ArduinoJson, etc)

================================================================================
BUILD ENVIRONMENTS
================================================================================

Production Build:
  platformio run
  Environment: charger_esp32_production
  Optimization: -O3 (fast)
  Binary Output: .pio/build/charger_esp32_production/firmware.bin

Debug Build:
  platformio run -e charger_esp32_debug
  Environment: charger_esp32_debug
  Optimization: -O0 (debugging)
  Symbols: Full debug symbols (-g)

Other useful commands:
  platformio run --target clean       Clean build
  platformio run --target upload      Upload to device
  platformio device monitor           View serial output
  platformio debug                    Start debugger
  platformio ci                       Continuous integration
